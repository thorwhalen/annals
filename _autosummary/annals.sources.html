annals.sources#

Item sources: everything the page lists, wherever it lives, as rows of one shape.

A source is a named, read-mostly collection of items. Two kinds exist:

  • PublishedSource: the documents agents published (a annals.store.DocStore).

  • FolderSource: a folder of files owned by someone else, read in place and never written (the crowsnest ledgers, and any other personal folder later). Its items are the folder’s files, keyed by their path relative to the folder.

Every source yields the same row shape, which the page lists, searches and filters:

key <source>:<id>, unique across sources (the API’s item id) source the source’s name; id the item’s id within it title, kind (see annals.store.kind_of()), session (who wrote it) time ISO 8601, UTC: publication time, or a file’s last modification size, tags (the item’s own; the catalog overlays the owner’s), excerpt

Sources are plain objects with a few methods (the Source protocol), so a new kind of folder is a new class or a new keyword argument, never a change to the API.

class annals.sources.FolderSource(root, *, name, title=None, exclude=('.*', '__pycache__', '*.pyc', '*.pyo'), session_of=<function top_level_name>)[source]#

Bases: Mapping

A folder of files, read in place and never written, as a Mapping of rows.

Keys are paths relative to root ("annals.md", "cw-liaise/design.md"), values listing rows. The folder is walked on every listing (a stat per file, cheap for hundreds), and a file is re-read only when its size or mtime changed. Hidden files and caches are skipped (exclude, the same patterns a directory publish skips), and so is anything that resolves outside root.

session_of(rel) names who wrote a file; the default suits a folder of per-session files and sub-folders (top_level_name()).

file_path(rel)[source]#

The file on disk; KeyError if it is absent, hidden, or escapes the root.

Only the canonical spelling of a path is accepted (a/b.md, not ./a/b.md, a//b.md or a/b.md/), so one file has one key.
