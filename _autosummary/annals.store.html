annals.store#

The document store: a flat set of documents, tags, groups and a recycle bin, as plain files.

Layout under the data root (local or remote, see annals.target):

docs/<id>/meta.json         one document: metadata
docs/<id>/<main file>       its content (index.html, report.md, ...), plus any assets
docs/<id>/.versions/<n>/    an earlier version, whole (its own meta.json and files)
docs/<id>.r<stamp>-<hex>/   a replacement not applied yet (``publish(replace=<id>)``)
trash/<id>/...              the same shape; the recycle bin is a move
groups/<gid>.json           a named, ordered list of document ids with its own URL

Flat on purpose: agents from many corpora do not share a hierarchy, and every placement decision costs tokens. Tags and groups carry the structure. Ids are time-sortable and readable (20261003-203301-starwars-theme-report-3f9a), so a listing is already in publication order and a URL says what it points to.

Plain files, written whole, because the same tree is written by rsync from another machine and read by the server; there is no index to keep consistent.

Living documents (one link that stays current) are a replace: the new files are written as a pending replacement next to the document, never over it, and whoever reads the store applies it (DocStore.settle()): the current files move under .versions/<n>/ and the replacement takes the id. Writing beside rather than over is what lets a replace travel through an outbox (a directory another machine pulls and empties): the pending directory is just another new directory to pull, and the store on the reading side applies it. Applying is a sequence of renames, each claimed atomically, so two readers never apply the same replacement twice and nothing is ever deleted.

publish(*sources, title=None, tags=(), source=None, text=None, filename='document.md', exclude=('.*', '__pycache__', '*.pyc', '*.pyo'), replace=None, artifact=None)[source]#

Publish files (or a directory, or text) as ONE document; return its meta.

One markdown or html file is the common case. A directory is published whole, with index.html (or the first renderable file) as the page shown. text publishes a string as filename instead of reading sources. exclude lists glob patterns skipped inside a directory (hidden files and caches by default; () keeps all).

replace (a document id) publishes a new version of that document instead of a new document: same id, same link, the current files kept as a version. It is written as a pending replacement and applied at once when this store settles (otherwise where the store is read). The returned meta says pending until then.

artifact (a claude.ai artifact link, see check_artifact_url()) is the interactive version of the page: the document’s page links out to it. A replacement that names none keeps the document’s current one.

Return type:

dict
