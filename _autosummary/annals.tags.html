annals.tags#

The owner’s tags: a MutableMapping from item key to tag list, kept apart from the items.

Tags the owner adds on the page are stored here, never in the items themselves: a folder source belongs to whoever writes it (a crowsnest ledger belongs to its session), so annals must not edit it, and a published document’s meta.json is the publisher’s record. An entry, once present, is the item’s whole tag list (it replaces the item’s own tags, so removing a tag the publisher set works too); deleting the entry falls back to them.

JsonTagStore, the default, is one JSON file under the data root (<data root>/tags/tags.json), written atomically. Any MutableMapping[str, list[str]] can replace it (mk_api(tags=...)), e.g. a table in a database.

class annals.tags.JsonTagStore(path)[source]#

Bases: MutableMapping

{item key: [tags]} in one JSON file, re-read when another process changed it.

Safe with several server processes on one machine: a write takes an exclusive flock on <file>.lock, re-reads the file, changes it and replaces it atomically, so two workers saving at once never lose each other’s change. A read re-reads the file whenever its inode, size or mtime changed (every write makes a new inode).
