annals.pagepdf#

Every published html page carries its own Download PDF button, and the PDF beside it.

A page is often read without the annals page around it: opened full page, its raw url mailed on, or shared. So at publish time the stored html itself gets a small “Download PDF” link (hidden when printing), pointing at <stem>.pdf in the same document:

  1. The page opts out (data-annals-pdf="off" on <html> or <body>, or annals publish --no-pdf): nothing is added.

  2. The page has its own button (any element with data-annals-pdf): nothing is added; it already says where its PDF is.

  3. The page declares its PDF (<link rel="alternate" type="application/pdf" href="...">): the button points there, and nothing is printed.

  4. The document already holds <stem>.pdf beside the page: the button points at it.

  5. Otherwise the page is printed to <stem>.pdf by pdf_renderer (default print_with_chromium(), pdfdol’s headless Chromium, in the pdf extra). When it

    cannot print (no Chromium, a page that will not load in time), the button calls the browser’s own print dialog instead, so it is never missing.

What this adds is one block wrapped in <!--annals-pdf--> markers (pure ASCII, so it suits a page in any charset), so publishing a page that already went through here (a new version through --replace) swaps the old button for a new one and prints the new page again. The page’s bytes are otherwise kept as they were, whatever their encoding.

annals.pagepdf.add_button(page, href)[source]#

page with a Download PDF link to href (or a print button when None).

One block goes right after <body> (or where the body would start): a <link rel="alternate"> declaring the PDF, so readers and agents find it, its style, and the button. Any button added earlier is replaced. href is used as given (quote a file name first: attach_pdf() does).

>>> page = "<!doctype html><html><head></head><body><p>x</p></body></html>"
>>> out = add_button(page, "x.pdf")
>>> 'href="x.pdf"' in out and 'type="application/pdf"' in out
True
>>> out.startswith("<!doctype html>")
True
>>> "window.print()" in add_button("<p>x</p>", None)
True
Return type:

str

annals.pagepdf.attach_pdf(root, main, files, *, pdf_renderer='default')[source]#

Give the staged html page root/main its PDF button (and its PDF).

Returns (files, pdf): files (relative to root) gains <stem>.pdf when it is printed here, and pdf is where the page’s PDF is (a file of the document, or the url the page declared), None when there is none. pdf_renderer defaults to DFLT_PDF_RENDERER; None never prints: the button links to a PDF the document or the page already has, else opens the print dialog. A renderer that fails is logged and treated the same way; publishing never fails for want of a PDF.

Return type:

tuple[list[str], str | None]

annals.pagepdf.declared_pdf(page)[source]#

The href of the page’s own <link rel="alternate" type="application/pdf">.

A link annals added itself does not count: that is not the page declaring one.

>>> declared_pdf('<link rel="alternate" type="application/pdf" href="guide.pdf">')
'guide.pdf'
>>> declared_pdf('<link rel="stylesheet" href="a.css">') is None
True

annals.pagepdf.print_with_chromium(page, *, timeout=60)[source]#

Print an html file to PDF with headless Chromium (pdfdol), with its print css.

Needs the pdf extra and playwright install chromium. It runs in a child process, killed (with its browser) after timeout seconds. Images marked loading="lazy" would print blank, so the page is printed from a copy without that attribute, beside it so its relative files still load.

Return type:

bytes
