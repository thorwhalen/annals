annals.sessions#

The sessions that made a document: each one’s name and the link that opens it.

A document’s meta carries them as sessions, a list of {"name": ..., "url": ...} in the order they first worked on it: the session that published it, then each session that published a new version (annals publish --replace). A group shows the sessions of its documents. The link is a claude.ai link (https://claude.ai/code/<bridge session id>), which only the owner can open; it is provenance, like source and artifact, so it is never part of the document’s own content and leaves with the meta: a share or a room shows an allowlist of meta fields that does not name it.

>>> sessions_of({"source": {"session": "b2", "session_url": "https://claude.ai/code/session_01X"}})
[{'name': 'b2', 'url': 'https://claude.ai/code/session_01X'}]
>>> merged_sessions([{"name": "a", "url": ""}], [{"name": "a", "url": "https://claude.ai/code/s"}, {"name": "b", "url": ""}])
[{'name': 'a', 'url': 'https://claude.ai/code/s'}, {'name': 'b', 'url': ''}]

annals.sessions.merged_sessions(*lists, limit=12)[source]#

The sessions of lists in order, one entry each: the same link, or the same name when one of the two has no link, is the same session (the link is kept). At most limit: the first session and the latest ones.

>>> [s["name"] for s in merged_sessions([{"name": str(i), "url": ""} for i in range(20)], limit=4)]
['0', '17', '18', '19']
Return type:
