annals.share#

Share links: one document (or a group) behind a public, unguessable, revocable link.

A share is a record under the data root, shares/<token>.json, written through the same annals.target.Target as the documents, so annals share works over ssh exactly like annals publish. The record is the whole contract; the owner’s API, the page’s Share button, the CLI and the public share server (annals.share_api) are surfaces over it:

{
 "token": "<22 url-safe chars, 128 random bits>",
 "title": "...", "created": "<iso>",
 "root": {"kind": "doc" | "group", "id": "<id>"},
 "docs": {"<doc id>": ["<file>", ...], ...},   # what the link may reach, and only that
 "expires": "<iso>" | null,
 "password": "scrypt$..." | null,               # a hash; the password is never stored
 "revoked": "<iso>" | null                       # a tombstone: a revoked link is a 404
}

docs is the scope. Every request of the public server is checked against it, never against what the link was made from: a file not listed is a 404 even when it sits beside the shared page, and a page or a link of the shared text that points outside the scope is removed before the text leaves the server (filter_refs()), so the recipient sees neither private ids nor private paths.

The password is a gate on the link, not an account: anyone who knows both may read. It is hashed with stdlib scrypt (the hasher seam takes argon2 or anything with hash/verify), and a correct one earns an HMAC cookie keyed by that hash, so changing the password or revoking the link ends every open session.

Tokens come from secrets.token_urlsafe() with 128 bits, as heed’s review pages do.

Bases: object

Stdlib hashlib.scrypt, stored as scrypt$n$r$p$salt$hash (base64).

The default needs no dependency; n=2**14, r=8 costs ~16 MB and tens of ms per check, which the attempt limit of the share server bounds.

create(ref, *, include=None, exclude=(), password=None, expires='7d', title=None)[source]#

Share a document or a group (ref is its id); return the record (no hash).

A document is shared with all its files unless include names some (the page itself always goes); include may also name annals pages the document links to, which then open inside the share. A group is shared with all its documents unless include names some. exclude removes files (or a group’s documents). A linked page goes with the files it shows. expires is anything parse_expires() reads, 7 days by default ("never" for none); password gates the link (at least MIN_PASSWORD_LEN characters).

annals.share.filter_refs(text, kind, *, files, shared, from_dir='', private_hosts=())[source]#

text with every reference outside the share removed (or rewritten).

files are the document’s files the share includes; shared(id) maps an annals id to where the recipient opens it (in scope) or None (not shared). A markdown image out of scope disappears, a link keeps its words; an html attribute goes; a bare annals url becomes “(link not shared)” and a bare annals id “(not shared)”. The text of the page itself is the owner’s: only references are touched. An absolute url on one of private_hosts (the owner’s own) goes too, whatever its path. Every kind of text is filtered (markdown, html, plain text, svg): only markdown syntax is markdown’s. Best effort by design, and the second line of defence: the share server answers 404 for anything outside the share however the text names it.

annals.share.parse_expires(value, *, now=None)[source]#

An expiry as an ISO UTC timestamp, or None for never.

None, "" and "never" mean never. Accepts a duration (30m, 12h, 7d, 2w), a date (2026-11-01: the END of that day, UTC, so the link works through the day named), an ISO timestamp (a naive one is UTC), or a datetime. A moment already past is refused.

>>> parse_expires("2d", now=datetime(2026, 1, 1, tzinfo=timezone.utc))
'2026-01-03T00:00:00+00:00'
>>> parse_expires("2026-01-05", now=datetime(2026, 1, 1, tzinfo=timezone.utc))
'2026-01-05T23:59:59+00:00'
