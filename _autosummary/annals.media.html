annals.media#

The media relay for published html pages: what a framed page plays, told to the page around it.

A spoken overview is an html page shown in a sandboxed frame, so the annals page cannot see its audio. This adds one inlined script (the page’s own ui/media-progress.js) to any html page that may play audio or video; the script posts what is played to the parent page, which records what the reader heard (annals.listening), and takes a “start at” from it. Opened on its own (no parent), the script does nothing.

annals.media.add_media_relay(html)[source]#

html with the media relay injected, unless it plays nothing or opts out.

>>> add_media_relay(b"<p>no media</p>") == b"<p>no media</p>"
True
>>> b"annalsMedia" in add_media_relay(b"<body><audio src=a.mp3></audio></body>")
True
>>> add_media_relay(b"<p>an audio overview</p>") == b"<p>an audio overview</p>"
True
