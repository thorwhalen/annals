annals.highlights#

Each reader’s highlights: passages of documents kept with a name, tags and a note.

A reader selects text on a document’s page and keeps it. The page side is the manicules widget (vendored under ui/vendor/manicules/); this module is the server side it talks to: what a highlight is allowed to be, where each reader’s are kept, and how they are searched. A highlight of a document’s whole title keeps the document itself, which is how a reader marks a favourite.

A highlight, as stored (the shape of manicules’ highlight.schema.json):

{"id": "hmf3k2x9a1b2c3", "name": "Bread notes-highlight-1",
 "target": {"source": {"id": "<doc id>", "title": "Bread notes", "url": "d/<doc id>"},
            "part": "body",
            "quote": {"exact": "85 percent water", "prefix": "A rye loaf takes ", "suffix": ", and"},
            "position": {"start": 310, "end": 327}},
 "comment": "the number I keep forgetting", "tags": ["rye"], "color": "green",
 "created": "2026-11-27T10:00:00+00:00"}

The target is two W3C Web Annotation selectors (the quote with its context, and where it was): the page finds the passage again from them after the document changed. whole in a target means the entire part, whatever it says now. The server never interprets a target; it bounds its size and keeps it.

Records live under the data root, one JSON file per reader (highlights/<reader>.json, {id: highlight}, the layout manicules’ own file store and CLI use), through annals.jsonstore.JsonFileStore; each reader’s two settings (the default colour, and whether a page shows all its highlights when it opens) are beside them (highlight-settings/<reader>.json). for_reader() is the seam: any (reader) -> ReaderHighlights callable can replace it (mk_api(highlights=...)), its records being anything with the three calls of Records. The routes the widget talks to are annals.highlights_api.mk_router().

>>> rec = clean({"target": {"source": {"id": "d1", "title": "Notes"}, "quote": {"exact": "three sites"}}},
...             names=["Notes-highlight-1"], now="2026-11-27T10:00:00+00:00", new_id=lambda: "h1")
>>> rec["name"], rec["target"]["part"], rec["tags"], rec["comment"]
('Notes-highlight-2', 'body', [], '')
>>> [h["id"] for h in search({"h1": rec}, "SITES notes")]
['h1']
>>> search({"h1": rec}, "sites absent")
[]
>>> clean_patch({"comment": "why", "color": None, "tags": ["b", "A", "a"]})
{'comment': 'why', 'color': None, 'tags': ['A', 'b']}
