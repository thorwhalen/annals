annals.docfilter#

Exact filters over a document’s meta, for a caller that polls: since, session, tag, source.

One place for the rules, so the CLI (annals ls), MCP and the HTTP /docs route cannot drift: since is an ISO date or time (local time unless it has an offset) or an age (6h, 2d); session, tag and each source key match whole values, never substrings; all given filters must hold. They are pure: the caller lists the documents (and puts the owner’s tags in, annals.catalog.with_owner_tags()) and this narrows them.

>>> docs = [{"id": "a", "tags": ["x"], "created": "2026-11-12T10:00:00+00:00", "source": {"session": "s1"}},
...         {"id": "b", "tags": ["y"], "created": "2026-11-10T10:00:00+00:00", "source": {"session": "s2"}}]
>>> [d["id"] for d in DocFilter.of(since="2026-11-11T00:00:00+00:00").apply(docs)]
['a']
>>> [d["id"] for d in DocFilter.of(session="s2", tag="y").apply(docs)]
['b']

annals.docfilter.parse_meta(meta, *, reserved=frozenset({'cwd', 'host', 'session', 'session_url'}))[source]#

["corpus=x", "issue=12"] (or one such string) as {"corpus": "x", "issue": "12"}.

A key in reserved (what annals records itself) is refused: writing it would forge provenance. A filter reads any key, so it passes reserved=frozenset().

>>> parse_meta(["corpus=annals", "issue=64"])
{'corpus': 'annals', 'issue': '64'}
>>> parse_meta(None)
{}
>>> parse_meta("oops")
Traceback (most recent call last):
...
ValueError: --meta takes key=value (for example corpus=annals), got 'oops'
>>> parse_meta(["host=h"])
Traceback (most recent call last):
...
ValueError: --meta cannot set 'host': annals records it (use --session for the session)
Return type:
