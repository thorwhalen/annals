annals.listening#

What each reader has heard of each audio document: percent heard, listens, where they stopped.

The page reports what was played, a few seconds at a time, as spans of the audio’s own timeline ([[start, end], ...] in seconds). The server keeps the union of those spans per reader and document, so the percent heard counts each second once, however often it was replayed or skipped back to, and two devices reporting the same minute add nothing twice. A listen is counted when playback reaches the end of audio that has been heard almost whole (DONE_SHARE), so dragging to the end is not a listen; a report carries the id of the play it belongs to, so a report sent twice (a retry, a page closing) counts one.

A record, per reader and document:

{"heard": [[0.0, 61.5], [90.0, 120.0]], "duration": 300.0, "position": 120.0,
 "listens": 1, "done": true, "updated": "2026-11-09T10:00:00+00:00"}

done is the reader’s own mark (“I have heard this”), set or cleared from the page; it is absent until they set it. status() reads a record as one of STATUSES.

Records live under the data root, one JSON file per reader (listening/<reader>.json), through annals.jsonstore.JsonFileStore. for_reader() is the seam: any (reader) -> store callable whose stores are Records can replace it (mk_api(listening=...)).

>>> merge_spans([[5, 10], [0, 3], [2, 6], [20, 20]])
[[0.0, 10.0]]
>>> rec = apply_report(None, {"spans": [[0, 30]], "duration": 100, "position": 30})
>>> percent(rec), status(rec)
(30, 'started')
>>> apply_report(None, {"spans": [[95, 100]], "duration": 100, "ended": "p0"})["listens"]  # dragged to the end
0
>>> rec = apply_report(rec, {"spans": [[30, 100]], "duration": 100, "position": 100, "ended": "p1"})
>>> rec = apply_report(rec, {"spans": [], "duration": 100, "position": 100, "ended": "p1"})
>>> percent(rec), rec["listens"], status(rec)
(100, 1, 'done')
