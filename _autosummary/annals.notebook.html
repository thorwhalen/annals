annals.notebook#

A share’s documents as separate notebook sources: one plain web page per text file.

A notebook product (NotebookLM, and Gemini’s notebooks, which share its sources) takes a web page by its link, one source per link, and several links pasted at once; it reads the page’s text and keeps its own copy. It does not unpack a zip, and its upload picker needs the files on the device first. So the fewest taps from an iPad is: tick the documents, copy one list of links, paste it into the notebook (see misc/docs/notebook-sources.md for the research behind this).

The links are a share’s (annals.share): unguessable, scoped to the documents ticked, expiring, revocable, and filtered like every shared text. This module only decides what becomes a source and how one looks:

GET <share link>/source/<doc id>/<file>   a script-free html page: <title>, the text

  • source_files(): which files of a document are sources (markdown and html pages, numbered files first, as annals.aggregate.numbered_first() orders them).

  • notebook_sources(): the {doc, file, title, url} rows of a share, in its order.

  • source_scope(): what a notebook share includes of a document: its source pages and the files they show, never the rest of a folder.

  • render_source(): one markdown file as its source page, shared-text rules applied twice: to the text (annals.share.filter_refs()), then to every link and image of the rendered page (annals.share.ref_decider() over markdown-it’s tokens), and any annals id left in it removed. Cached, and rendered only up to RENDER_MAX_BYTES (a larger file is sent as escaped text): it is a public route.

  • source_page(): the page a notebook reads. Its <title> is the document’s title, which the notebook shows as the source’s name, so the sources can be told apart.

  • markdown_html(): markdown to html; markdown-it-py when installed (the pdf extra), else the text escaped in a <pre>, which a notebook reads as well.

annals.notebook.markdown_html(text, *, rewrite_url=None, render=None)[source]#

text (markdown) as html; every link and image through rewrite_url.

render(text, rewrite_url) overrides the default renderer. Without one (no markdown-it-py) the text is escaped in a <pre>: no markup, so no link.

Return type:

str

annals.notebook.notebook_sources(scope, *, link)[source]#

One row per source file of scope ((meta, files) pairs, in the share’s order).

{"sources": [{"doc", "file", "title", "url"}], "skipped": [{"doc", "title", "kinds"}]}; skipped names the documents with nothing a notebook can take from a link (only images, audio, pdf…), so the page can say why they are missing.

Return type:

dict

annals.notebook.render_source(text, *, title, link, doc_id, rel, files, sources, shared_ids, root_id='', private_hosts=())[source]#

One markdown file of a share as its source page (see the module docstring).

Every argument is hashable, so a page is rendered once per text and scope. shared_ids are the annals ids the share includes (opened at <link>/d/<id>), root_id the shared group’s (opened at <link>/).

annals.notebook.source_link_rewriter(decide, *, link, doc_id, from_dir, sources)[source]#

url -> url | None for a source page, which has no <base>.

decide (annals.share.ref_decider()) says what may stay; a relative file it keeps becomes absolute here: another source page of the document links to that page, any other file to the share’s raw file. Anchors and web links stay as they are.

Return type:

Callable[[str], str | None]
