annals.titles#

A title for a file whose name says nothing: overview.mp3, output.html, index.md.

A document is titled by what it says (a # heading, a <title>), else by its file name. Tools that make media often name every output the same (podpatch and hailing both write <folder>/overview.mp3), so seven audio overviews were all titled “overview”. When the file name is one of GENERIC_STEMS, the title comes from beside the file instead: the title of a JSON manifest in its folder (TITLE_FILES), else the folder’s own name without its date and hash, but only when the folder was made by a tool (its name carries a date stamp or a short hash): a person’s folder (their home, a repo, a client’s) never names a document, since a title shows wherever the document is shared.

>>> is_generic("overview") and is_generic("Final_Output") and not is_generic("theremin")
True
>>> folder_title("20261119-223540-theremin-and-gesture-controlled-7d32")
'theremin and gesture controlled'

Module Attributes

GENERIC_STEMS

file names (without extension) that never title a document on their own

TITLE_FILES

files a maker writes beside its output whose title names it, tried in order

MAX_TITLE

the longest title taken from a manifest (a rename allows as much)

UNINFORMATIVE_FOLDERS

folder names that say nothing either (a title from one would be noise)

Functions

folder_title(name)

A tool's output folder's name as a title: date stamp and trailing hash dropped, separators spaced; "" for a folder no tool made (no stamp and no hash), or one whose words are only digits and hex (a uuid, a temporary folder's name).

is_generic(stem, *[, generic])

Whether a file name (without extension) says nothing about what it holds: one of generic, or two of them ("final output", "audio overview").

title_beside(path)

A title for the file path from what is beside it (see the module doc), or None when its folder says nothing either.

annals.titles.title_beside(path)[source]#

A title for the file path from what is beside it (see the module doc), or None when its folder says nothing either.

>>> import tempfile, os
>>> d = Path(tempfile.mkdtemp()) / "20261119-223540-theremin-7d32"; d.mkdir()
>>> title_beside(d / "overview.mp3")
'theremin'
>>> _ = (d / "manifest.json").write_text('{"title": "The Theremin: Invention, Spies"}')
>>> title_beside(d / "overview.mp3")
'The Theremin: Invention, Spies'
