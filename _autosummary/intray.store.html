intray.store

intray.store¶

The document store: a flat set of documents, tags, groups and a recycle bin, as plain files.

Layout under the data root (local or remote, see intray.target):

docs/<id>/meta.json         one document: metadata
docs/<id>/<main file>       its content (index.html, report.md, ...), plus any assets
trash/<id>/...              the same shape; the recycle bin is a move
groups/<gid>.json           a named, ordered list of document ids with its own URL

Flat on purpose: agents from many corpora do not share a hierarchy, and every placement decision costs tokens. Tags and groups carry the structure. Ids are time-sortable and readable (20261003-203301-starwars-theme-report-3f9a), so a listing is already in publication order and a URL says what it points to.

Plain files, written whole, because the same tree is written by rsync from another machine and read by the server; there is no index to keep consistent.
