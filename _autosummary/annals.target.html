annals.target#

The transport seam: a document tree lands in a directory, here or on another machine.

A Target is the handful of filesystem verbs the store needs (put a directory, move, remove, read and write a text file, list sub-directories, read every meta.json under a directory). Two implementations:

  • LocalTarget: a directory on this machine, plain pathlib/shutil.

  • SshTarget: host:path on another machine, through the system ssh and rsync in batch mode (no prompts, so an agent never hangs). The host is whatever the user’s ~/.ssh/config resolves, so an alias such as tw works.

parse_target() picks one from a string. An HTTP target (a bearer-token ingest endpoint) is the declared replacement for the ssh one and is not built yet.
