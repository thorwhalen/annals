annals.combine#

Many files of many kinds as ONE document: a Markdown, html or PDF file.

The mechanism is a registry. A converter turns one file of one kind into a part of the output format (markdown text, an html fragment, a PDF); a joiner puts the parts of a format together (a table of contents and a section each; bookmarks and pages). Which pairs exist is the table REGISTRY, filled by register():

@register("pdf", "md", requires=("pdfdol",))
def pdf_to_md(item, ctx): ...

so a new pair (docx to pdf, say) is one decorated function, and the web page, the API and the CLI all learn it from supported() without a change.

What goes in:

=========  ===========  =======================================================
input      to md        to html / to pdf
=========  ===========  =======================================================
md         as it is     rendered (images of the document inside)
html       converted    its text and structure (scripts and styles dropped)
text       a code block a preformatted block
pdf        its text     html: its text; pdf: its pages, joined as they are
image      -            a figure (html) / a page of its own (pdf)
=========  ===========  =======================================================

Audio, video and other files have no place in a document: they are reported as left out, each with the reason, never silently dropped. A file that cannot be read (a damaged or password-protected PDF) is left out the same way, and the others still go in.

An image or a text file that sits in a document with pages (markdown, html, a PDF) is part of that document, not a section of its own: a report and its figures combine as the report.

Heavy libraries load only when a pair needs them (WeasyPrint for PDF pages, pypdf and pdfdol to join and read PDFs, markdownify for html to markdown); a missing one is a annals.requirements.MissingDependency that says what to install, raised before any work starts. Nothing is stored: the document is made per call.

>>> combined = combine([_demo_source({"b.md": "# B\ntext", "a.md": "hello"})], "md", title="T")
>>> combined.sections, combined.ext
(2, 'md')
>>> print(combined.data.decode().splitlines()[0])
# T

annals.combine.combine(sources, fmt='md', *, title='', demote=1, toc=True, unwrap=True, order=<function numbered_first>, max_text_bytes=8000000, max_input_bytes=120000000, registry=None)[source]#

Every usable file of sources as one fmt (“md”, “html” or “pdf”) file.

sources are the documents (Source), in their order; files are arranged by order (annals.aggregate.numbered_first(): numbered names first, numerically; None keeps the documents’ order). demote is how far an embedded markdown file’s headings go down in a markdown output, which also takes toc (a table of contents) and unwrap (join hard-wrapped lines). max_text_bytes caps all the text read (annals.aggregate.TooLarge), max_input_bytes all the files together.

A file with no converter, or that cannot be read, is left out and listed in Combined.skipped with the reason. Raises NothingToCombine when nothing is left, annals.requirements.MissingDependency when a library the conversions need is not installed (before any work), and ValueError for an unknown fmt.

Combined

annals.combine.html_body(text, *, rewrite_src=<function <lambda>>, demote=0)[source]#

The content of an html page as a safe fragment: its structure and words, nothing live.

Only a fixed set of tags survives, with a few plain attributes: no script, style, frame, form, event handler, class or id; a link keeps only an http(s) or mailto address. rewrite_src(src) decides each image: the url to show it from, or None for its alt text instead (an image is never loaded from where the page says). demote pushes headings that many levels down. Unbalanced tags are closed, so a fragment can never swallow what is joined after it.

>>> html_body('<body><script>x()</script><h1 onclick="x()">Hi</h1><a href="javascript:x()">y</a></body>')
'<h1>Hi</h1><a>y</a>'
Return type:

str

annals.combine.items_of(sources, fmt)[source]#

The files to try for a fmt output, in the documents’ order.

A document with pages (markdown, html, PDF) contributes those; its images and text files are its own parts. A document with none contributes whatever it holds, so what cannot be used (a video) is reported and not silently missing. A folder, or a document with several such files, names each by its title then the file (Report/01-intro.md).
