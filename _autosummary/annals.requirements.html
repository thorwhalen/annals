annals.requirements#

Optional dependencies, checked where they are needed and explained when they are missing.

annals installs light: a heavy library (WeasyPrint for PDFs, pypdf for joining them, markdownify for html to markdown) is imported only when the conversion that needs it runs, and a missing one is a MissingDependency that says which conversion needed it and the exact command that fixes it, never a bare ImportError from deep inside a library.

>>> check_requirements("json", what="anything")        # present: returns quietly
>>> try:
...     check_requirements("no_such_module_xyz", what="Combining into PDF")
... except MissingDependency as e:
...     print(str(e).splitlines()[0])
Combining into PDF needs no_such_module_xyz, which is not installed.

The pip name and the hint for a module are in PACKAGES, so a new optional library is one entry there.
