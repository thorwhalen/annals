annals.records#

The published documents as records for a retrieval index, so an agent can find one by meaning.

annals keeps its own full-text index for the page’s search box (annals.search). Searching by meaning (“the report comparing local TTS engines”) is ir’s job, and ir takes any package’s records through a named callable: register this one once (from Python; ir register on the command line has no records option) and ir rebuilds from it:

import ir, annals.records
ir.register("annals", "records", fetcher="annals.records:records",
            metadata_keys=list(annals.records.METADATA_KEYS))
ir.build_corpus("annals")       # then: ir discover annals "the report comparing local TTS engines"

One record per current document (the bin and earlier versions are not indexed). A markdown, text or html document brings its text (html without its markup); a folder or a document of several markdown files brings them as one text, as annals aggregate makes it; any other kind (an image, a PDF) brings its title and excerpt, so it can still be found. Overviews and combined documents duplicate their sources, so they are left out unless asked for. A document the owner or the publisher tagged noindex or private (any case) is never yielded.

Run it where the documents are: it refuses an outbox and a remote target, because the owner’s tags (the privacy gate) live beside the documents, and an index built from a partial view would drop the rest. Two things belong to the index, not to this function: ir decides a record changed by hashing its text, so a retag or retitle reaches the index’s filters only on a rebuild that is full (which also prunes a document trashed, purged or newly tagged noindex; register with full builds). url uses this machine’s base_url.

>>> import tempfile, pathlib
>>> from annals.store import DocStore
>>> root = pathlib.Path(tempfile.mkdtemp())
>>> store = DocStore(root)
>>> _ = store.publish(text="# Local TTS engines\n\nPiper and Kokoro compared.", title="TTS", tags=["research"])
>>> _ = store.publish(text="# Secret\n\nnot for an index", title="S", tags=["noindex"])
>>> [(r["title"], r["tags"], "Kokoro" in r["text"]) for r in records(target=str(root))]
[('TTS', 'research', True)]
